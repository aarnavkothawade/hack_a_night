Leakage profile

What an honest-but-curious server can and cannot learn from everything above.

{{ icon('eye') }}Learns

  • Access pattern: which document IDs match a query and which blobs are downloaded.
  • Search pattern: whether two queries repeat a term, because equal words give equal labels.
  • Result counts: how many postings each term has and how many terms a query uses.
  • Sizes & timing: blob sizes, upload times, number of unique keywords per upload.
  • Blind-index equality: which documents share the same department or classification value.

{{ icon('eye-off') }}Cannot learn

  • Document contents or filenames, which are AES-256-GCM encrypted.
  • Plaintext keywords or query text, which only ever arrive as HMAC outputs.
  • Boolean structure: AND, OR and NOT are evaluated inside the portal.
  • Keys: master.key, K_enc, K_idx, K_tok and K_blind never leave the portal.
